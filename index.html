Металлы + кислоты-окислители

Схема: что получится в зависимости от кислоты и металла

H2SO4(конц.)
активный металл Li—Zn−2Соль + H2S + H2O
металл средней активности Cd—Pb0Соль + S + H2O
неактивный металл (после H2) и Fe+4Соль + SO2 + H2O
HNO3(конц.)
независимо от активности металла+4Соль + NO2 + H2O
HNO3(разб.)
активный металл Li—Zn0Соль + N2 + H2O
металл средней активности Fe—Pb+1Соль + N2O + H2O
неактивный металл (после H2)+2Соль + NO + H2O
HNO3(оч. разб.)
активный металл−3Соль + NH4NO3 + H2O
H2SO4(разб.)
металлы до H2 в ряду активности (кислота как обычная)0Соль + H2
металлы после H2 (Cu, Hg, Ag, Pt, Au)не реагируют
Au и Pt не реагируют ни с H2SO4(конц.), ни с HNO3. Al, Fe, Cr на холоду пассивируются в концентрированных H2SO4 и HNO3, реакция идёт при нагревании. Азотная кислота любой концентрации водород с металлами почти не выделяет.

3Ni + 4H2SO4(конц.) => 3NiSO4 + S↓ + 4H2O | средняя активность → S

Cu + 2H2SO4(конц.) ={t}> CuSO4 + SO2↑ + 2H2O | неактивный → SO2

2Fe + 6H2SO4(конц.) ={t}> Fe2(SO4)3 + 3SO2↑ + 6H2O | Fe до +3

Zn + H2SO4(разб.) => ZnSO4 + H2↑ | кислота как неокислитель

Cu + 4HNO3(конц.) => Cu(NO3)2 + 2NO2↑ + 2H2O

Fe + 6HNO3(конц.) ={t}> Fe(NO3)3 + 3NO2↑ + 3H2O

5Zn + 12HNO3(разб.) => 5Zn(NO3)2 + N2↑ + 6H2O

4Pb + 10HNO3(разб.) => 4Pb(NO3)2 + N2O↑ + 5H2O | средняя активность → N2O

3Cu + 8HNO3(разб.) => 3Cu(NO3)2 + 2NO↑ + 4H2O | неактивный → NO

4Zn + 10HNO3(оч. разб.) => 4Zn(NO3)2 + NH4NO3 + 3H2O

Диспропорционирование галогенов в щелочах
Диспропорционирование: один элемент и окисляется, и восстанавливается. Cl⁰ → Cl⁻ + Cl⁺ (на холоду, гипохлорит) или Cl⁻ + Cl⁵⁺ (при нагревании, хлорат). Запоминалка: холодная щёлочь → гипо-, горячая → хлорат.

Хлор

Cl2 + 2NaOH ={хол.}> NaCl + NaClO + H2O | гипохлорит натрия

3Cl2 + 6KOH ={t}> 5KCl + KClO3 + 3H2O | хлорат калия (бертолетова соль)

2Cl2 + 2Ca(OH)2 => CaCl2 + Ca(ClO)2 + 2H2O | хлорная известь

Cl2 + H2O ⇄ HCl + HClO | в воде тоже диспропорционирует

Бром и иод

Br2 + 2NaOH ={0°C}> NaBr + NaBrO + H2O

3Br2 + 6KOH ={t}> 5KBr + KBrO3 + 3H2O

3I2 + 6NaOH => 5NaI + NaIO3 + 3H2O | иод даёт иодат даже без нагревания

Фтор не диспропорционирует: он самый электроотрицательный и не имеет положительных степеней окисления. Другие примеры диспропорционирования: 2NO2 + 2NaOH → NaNO2 + NaNO3 + H2O и 3S + 6KOH →(t) 2K2S + K2SO3 + 3H2O.
Несолеобразующие оксиды: CO, NO, N2O
Несолеобразующие оксиды (CO, NO, N2O, иногда SiO) не реагируют с водой, кислотами и щелочами с образованием солей. Зато вступают в окислительно-восстановительные реакции. NO2 к ним не относится: он реагирует со щёлочью.

CO (угарный газ)

2CO + O2 => 2CO2 | горит синим пламенем

CO + CuO ={t}> Cu + CO2 | восстановитель

Fe2O3 + 3CO ={t}> 2Fe + 3CO2 | доменный процесс

CO + Cl2 ={свет}> COCl2 | фосген

CO + 2H2 ={t,p,кат.}> CH3OH | метанол

NO (оксид азота(II))

2NO + O2 => 2NO2 | на воздухе буреет

2NO + Cl2 => 2NOCl

2NO + 2CO ={кат.}> N2 + 2CO2 | нейтрализатор в авто

2NO + 2H2 ={t}> N2 + 2H2O

N2O (веселящий газ)

2N2O ={t}> 2N2 + O2 | разложение

N2O + H2 ={t}> N2 + H2O

N2O + Mg ={t}> N2 + MgO

Реакции «NO2 для сравнения»

4NO2 + O2 + 2H2O => 4HNO3

2NO2 + 2NaOH => NaNO2 + NaNO3 + H2O

Железо с галогенами и галогеноводородами
Сильные окислители (F2, Cl2, Br2) доводят железо до +3. Слабый окислитель I2 и ионы H⁺ в кислотах дают +2. FeI3 не существует: Fe³⁺ окисляет I⁻.

С галогенами

2Fe + 3F2 => 2FeF3

2Fe + 3Cl2 ={t}> 2FeCl3

2Fe + 3Br2 ={t}> 2FeBr3

Fe + I2 ={t}> FeI2 | единственное исключение

С галогеноводородными кислотами

Fe + 2HCl => FeCl2 + H2↑

Fe + 2HBr => FeBr2 + H2↑

Fe + 2HI => FeI2 + H2↑

Fe + 2HF => FeF2 + H2↑

Переходы Fe(II) ⇄ Fe(III)

2FeCl2 + Cl2 => 2FeCl3

2FeCl3 + Fe => 3FeCl2

2FeCl3 + 2KI => 2FeCl2 + I2 + 2KCl

2FeCl3 + Cu => 2FeCl2 + CuCl2

2FeCl3 + H2S => 2FeCl2 + S↓ + 2HCl

FeCl3 + 3NaOH => Fe(OH)3↓ + 3NaCl | бурый осадок
